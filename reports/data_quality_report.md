## Detection thresholds

- Distance tolerance: claimed vs reference distance difference > 20 km
- High-cost anomaly: cost per litre-km > Q3 + 3 x IQR = 0.00642 ZMW per litre-km
- Cost per litre-km normalised on reference distance, rows with missing or non-positive volume/distance/cost excluded from the threshold calculation
